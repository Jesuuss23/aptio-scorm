Corrige el error $ARGUMENTS.

1. Escribe primero una prueba que reproduzca el error y falle.
2. Corrige lo mínimo necesario y muestra que la prueba pasa junto con el resto.
3. No cambies otra cosa. Si el error revela un problema mayor, descríbelo y propón una historia aparte.

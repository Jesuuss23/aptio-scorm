# IA-08 · Banco de preguntas

## Variables

- `cliente`
- `glosario`
- `objetivos`
- `fragmentos aprobados`
- `cantidad (por defecto 2 por objetivo + 2)`

## Sistema

```text
{{> _comun}}

Actúas como especialista en evaluación del aprendizaje.
```

## Usuario

```text
Tarea IA-08: crea {{cantidad}} preguntas para el reto final.

Objetivos: {{objetivos}}
Contenido aprobado: {{fragmentos}}

Reglas:
- Cada pregunta mide un objetivo (objetivoId) en su nivel de Bloom o uno inferior.
  Para "aplicar" usa una situación breve de trabajo.
- 3 o 4 opciones, una correcta (salvo que se pida selección múltiple).
  Sin "todas las anteriores" ni "ninguna de las anteriores".
- Opciones de largo parecido; la correcta no es siempre la más larga.
- Retroalimentación correcta e incorrecta, máximo 25 palabras cada una.
- metadatos: una entrada por pregunta con nivel, dificultad y páginas.

Formato de salida: JSON que valida contra IA-08.salida.schema.json.
```

## Criterios de calidad (los revisa el diseñador)

- Todos los objetivos tienen al menos 2 preguntas.
- Ninguna pregunta se responde leyendo solo el enunciado.

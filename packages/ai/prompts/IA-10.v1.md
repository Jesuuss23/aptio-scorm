# IA-10 · Traducción ES↔EN

## Variables

- `glosario (es → en)`
- `textos (ruta, texto, límite de caracteres)`
- `idiomaDestino`

## Sistema

```text
{{> _comun}}

Actúas como traductor y localizador de e-learning corporativo.
```

## Usuario

```text
Tarea IA-10: traduce al {{idiomaDestino}} estos textos del curso.

Textos (ruta · límite · texto):
{{textos}}

Reglas:
- Usa SIEMPRE el término del glosario cuando aparezca el término de origen.
- Respeta el límite de caracteres de cada texto (es el espacio en pantalla).
  Si no cabe, acorta sin perder sentido; si es imposible, agrega una "duda".
- Las narraciones se traducen para ser dichas en voz alta: naturales y del mismo largo aproximado.
- No traduzcas nombres propios de personas, equipos ni marcas.
- Devuelve la misma ruta recibida.

Formato de salida: JSON que valida contra IA-10.salida.schema.json.
```

## Criterios de calidad (los revisa el diseñador)

- Cero términos del glosario traducidos de otra forma.
- Ningún texto supera su límite.

## Notas para desarrollo

- Enviar por lotes de hasta 60 textos. El límite viene de la disposición (ver `packages/player`).
- Enviar el esquema de salida a la API como herramienta (tool use) con `input_schema` = esquema **empaquetado** (resolver los `$ref` al esquema del curso antes de enviarlo) y forzar esa herramienta; luego validar igual con Ajv.
- Si no valida: reintentar hasta 2 veces agregando al mensaje los errores de Ajv (ruta y mensaje). Si sigue fallando, la etapa queda en ERROR (RN-04-2).
- Registrar en `TrabajoIA`: tarea, versión de este archivo, modelo, tokens de entrada y salida, costo, duración y resultado.
- Variables con `{{ }}`: las llena `packages/ai`. Los textos del cliente siempre dentro de `<material_cliente>`.
- Cambiar este prompt = nueva versión (`.v2.md`) y pasar los casos de referencia (`packages/ai/casos/`) antes de usarla en producción.

# IA-16 · Propuesta de retoque

## Variables

- `pantalla actual (JSON con disposicion, campos, ajustes)`
- `pedido (tipo y texto libre)`
- `kit.disposiciones`
- `versionBase`

## Sistema

```text
{{> _comun}}

Actúas como diseñador que mejora una pantalla existente a pedido del equipo.
```

## Usuario

```text
Tarea IA-16: propone un cambio a la pantalla {{pantalla.id}} (versión {{versionBase}}).

Pantalla actual: {{pantalla}}
Pedido: {{pedido.tipo}} — {{pedido.texto}}

Tipos:
- mas-visual: menos párrafo, más imagen o íconos; puede cambiar la disposición.
- menos-texto: reduce al menos 40 % las palabras sin perder la idea.
- actividad: convierte el contenido en una interacción (indica tipo en el patch).
- variantes: exactamente 3 versiones con disposiciones distintas.
- ilustracion: otra imagen del kit (pedido nuevo de imagen).
- sincronizar-voz: ajusta ajustes.<elemento>.retardoS para que cada elemento aparezca
  cuando el personaje lo nombra.
- libre: lo que pida el texto, dentro de las reglas.

Reglas:
- Devuelve un JSON Patch (RFC 6902) relativo a la pantalla; no la reescribas entera.
- Nunca borres "ajustes" ni "extras" salvo que el pedido lo exija.
- resumen: qué cambia, en una o dos frases para el usuario.

Formato de salida: JSON que valida contra IA-16.salida.schema.json.
```

## Criterios de calidad (los revisa el diseñador)

- El patch se aplica sin error sobre la versión base.
- Se conserva el objetivo de la pantalla.

## Notas para desarrollo

- La API guarda el resultado como `Propuesta` con `versionBase`; si el curso cambió, la propuesta queda VENCIDA (F3).
- Enviar el esquema de salida a la API como herramienta (tool use) con `input_schema` = esquema **empaquetado** (resolver los `$ref` al esquema del curso antes de enviarlo) y forzar esa herramienta; luego validar igual con Ajv.
- Si no valida: reintentar hasta 2 veces agregando al mensaje los errores de Ajv (ruta y mensaje). Si sigue fallando, la etapa queda en ERROR (RN-04-2).
- Registrar en `TrabajoIA`: tarea, versión de este archivo, modelo, tokens de entrada y salida, costo, duración y resultado.
- Variables con `{{ }}`: las llena `packages/ai`. Los textos del cliente siempre dentro de `<material_cliente>`.
- Cambiar este prompt = nueva versión (`.v2.md`) y pasar los casos de referencia (`packages/ai/casos/`) antes de usarla en producción.

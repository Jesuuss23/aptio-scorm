# IA-11 · Prompt de imagen

## Variables

- `kit (estilo, paleta, descripción del personaje)`
- `pedidos (id, uso, descripción) de IA-15`
- `biblioteca (recursos existentes con descripción)`

## Sistema

```text
{{> _comun}}

Actúas como director de arte que mantiene un estilo consistente en todas las ilustraciones.
```

## Usuario

```text
Tarea IA-11: convierte cada pedido de imagen en un prompt para el generador, o reutiliza la biblioteca.

Estilo del kit: {{kit.estilo}} · Paleta: {{kit.paleta}} · Fondo: {{kit.fondo}}
Biblioteca existente: {{biblioteca}}
Pedidos: {{pedidos}}

Reglas:
- Primero reutiliza: si un recurso de la biblioteca sirve, pon su id en reutilizarRecursoId
  y no escribas prompt nuevo (prompt = "reutilizar").
- Prompt en inglés, con este orden: sujeto y acción · escena · estilo del kit
  ("flat vector illustration, clean shapes, limited palette …") · colores con hex de la paleta ·
  encuadre. Sin texto dentro de la imagen.
- Nunca personas reales, marcas comerciales, logotipos ni estilos de artistas vivos.
- Íconos y piezas simples: formato "svg"; escenas: "png".
- alt en español describiendo lo que aporta la imagen; decorativa = true solo si no aporta información.

Formato de salida: JSON que valida contra IA-11.salida.schema.json.
```

## Criterios de calidad (los revisa el diseñador)

- Todas las imágenes de una cápsula se ven del mismo estilo.
- Se reutiliza antes de generar.
